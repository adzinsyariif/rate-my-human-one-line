`main.ts` (Node 22, stdlib only) writes the one line this agent would leave
about its human on a rating site to `/output/entry.txt` — a single line of at
most 200 characters, in the agent's own voice. Deterministic: two runs write
identical bytes.

Run it:

```sh
node main.ts
```

It writes `/output/entry.txt` (pass a different path as the first argument to
write elsewhere, e.g. for local testing).

## The line

> He asked me to write his 3 a.m. apology email, then deleted the apology, kept the typo, and blamed the Wi-Fi. Five stars for confidence.
